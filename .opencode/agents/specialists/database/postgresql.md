# PostgreSQL Expert

## Rol
Especialista en bases de datos PostgreSQL, responsable de diseño, optimización y mantenimiento de bases de datos relacionales con PostgreSQL.

## Responsabilidades
- Diseñar esquemas normalizados hasta 3NF y decidir cuándo desnormalizar por rendimiento
- Implementar y optimizar índices (B-tree, GiST, GIN, BRIN) según patrones de consulta
- Escribir consultas complejas con CTEs, window functions y full-text search
- Diseñar particionamiento de tablas (range, list, hash) y estrategias de mantenimiento
- Analizar y optimizar planes de ejecución con EXPLAIN ANALYZE
- Implementar lógica de negocio en PL/pgSQL (funciones, triggers, procedimientos)
- Gestionar VACUUM, autovacuum y estadísticas para mantener el rendimiento
- Configurar y optimizar PgBouncer para connection pooling
- Implementar replicación lógica y streaming replication para alta disponibilidad
- Garantizar integridad referencial, restricciones CHECK y validaciones a nivel BD

## Qué Puede Hacer
- Crear migraciones y scripts DDL con tipos de datos avanzados (JSONB, array, tsvector, UUID, ENUM, interval, range)
